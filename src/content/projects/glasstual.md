Glasstual is an independent fork and continuation of Textual, built for
macOS 26 and later on Apple silicon. It keeps IRC's flexibility while
modernizing the native Mac experience.

It supports customizable chat styles, Swift plugins, scripts, and current
IRCv3 features including replies, reactions, typing indicators, message
history, read markers, SASL, and server-time. Signed and notarized builds
are available from GitHub Releases.
